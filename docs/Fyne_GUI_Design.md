# Media Organizer V2 - Fyne GUI界面设计与交互逻辑规划

**项目目标：**
为Media Organizer V2增加一个简洁高效的macOS桌面GUI界面，极致贴合Go生态，提升用户易用性和可视化操作体验。

---

## 1. 界面总体结构

- **主窗口**（菜单栏＋分栏设计）
  - 顶部菜单栏 （文件、编辑、操作、帮助等）
  - 左侧侧边栏（主要导航/状态区）
  - 主内容区（动态切换MainView、配置、进度等）

## 3. 典型用户操作流程（交互逻辑简述）

1. 用户双击启动应用，进入主界面
2. 通过文件夹选择框，设置源目录和目标目录
3. 用单选框/下拉框选择整理模式、重复检测方式等参数
4. 点击“开始整理”按钮，界面切换为进度模式，展示当前进度和操作日志
5. 整理中可以查看详细日志、随时中止/暂停任务
6. 处理完成弹窗汇总结果并可直接打开目标目录
7. 用户可切换到历史记录/设置Tab，浏览历史、调整参数、导入/导出配置

## 4. 设计风格及布局建议
- 遵循macOS桌面软件UI习惯，整体扁平化风格
- 主色调可与现有终端TUI风格对齐，兼容暗色/亮色
- 采用原生Fyne控件实现所有功能，保持高一致性
- 控件布局清晰分区，极力压缩用户点击步数
- 支持全键盘操作，Tab/快捷键可穿梭主要功能

## 5. 技术实施小贴士
- 推荐主界面采用fyne.ContainerWithLayout(布局)嵌套，分区管理
- 文件夹选择用`dialog.ShowFolderOpen`/`dialog.ShowFileSave`
- 表格/进度用`widget.ProgressBar`、`widget.Table`
- 日志窗口用`widget.Entry`（多行只读）
- 历史记录可本地持久化为JSON
- 支持并发/进程处理时可用go routine + Channel联动UI刷新
- CLI模式与GUI共存，自动识别启动参数决定是否弹出界面

## 6. 补充说明
- 保持配置JSON与CLI版本兼容，共享配置逻辑
- 需考虑批量文件大数据量处理时UI不卡顿（异步+并发）
- 后续可扩展图片预览、拖拽交互、批量标签添加等个人化功能
