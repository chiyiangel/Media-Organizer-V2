## 📝 使用说明

### 启动 GUI 模式

```bash
# 直接启动 GUI（使用默认配置）
./build/media-organizer --mode gui

# 或使用配置文件启动
./build/media-organizer --mode gui --config config.json
```

### 编译

```bash
# 编译
make build

# 或手动编译
go build -o build/media-organizer ./cmd/organizer
```

### 目录结构

```
internal/gui/
├── app.go                 # 主应用入口和框架
└── screens/              # 各个界面实现
    ├── screen.go         # Screen 接口定义
    ├── config.go         # 配置界面
    ├── progress.go       # 进度界面
    ├── history.go        # 历史记录界面
    └── settings.go       # 设置界面
```

## 💡 技术要点

- **框架选择**: Fyne v2.7.2（原生 Go GUI 框架）
- **架构模式**: Screen 接口 + 导航系统
- **状态管理**: 通过 App 对象共享 config
- **异步处理**: 需要使用 goroutine + channel 实现文件处理
- **跨平台**: Fyne 原生支持 macOS/Windows/Linux
